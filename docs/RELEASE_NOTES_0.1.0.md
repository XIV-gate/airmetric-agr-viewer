# Airmetric AGR Viewer 0.1.0

Просмотрщик архивов АГР для Blender 4.2 и новее.

- Русская панель Airmetric с подсказками.
- Открытие отдельных ZIP и ZIP с вложенными архивами.
- Независимые переключатели ВПМ и НПМ, стекло и подсветка.
- Кнопки материалов, масштаба и направлений вида.
- Работа в несохранённой сцене.
- Встроенные текстуры и удаление временной распаковки.
- Обновление через интерфейс с выбором версии.

Скачайте **airmetric_agr_viewer-0.1.0.zip**, не распаковывая установите его через
**Blender → Edit → Preferences → Add-ons → Install from Disk…** и включите плагин.
Затем в окне 3D нажмите **N → Airmetric**.

[Инструкция со скриншотами](https://github.com/XIV-gate/airmetric-agr-viewer/blob/main/docs/USER_GUIDE_RU.md).
