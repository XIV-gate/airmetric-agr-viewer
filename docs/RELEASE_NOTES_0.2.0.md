# Airmetric AGR Viewer 0.2.0

- Предварительная проверка выбранных ZIP с причинами пропуска.
- Загрузка архивов по очереди, видимый прогресс и остановка между архивами.
- Пропуск или замена повторного архива без лишних копий.
- Ошибка отдельного архива сохраняет остальные загруженные модели.
- Большая красная кнопка «Очистить сцену» с подтверждением.
- Освобождение неиспользуемых материалов и текстур при очистке.
- Кнопка «Инструкция» и отдельное руководство для каждой версии.
- Исправлено восстановление недостающих карт материалов.

[Инструкция 0.2.0](USER_GUIDE_0.2.0_RU.md) · [Инструкция 0.1.0](USER_GUIDE_RU.md)

При чтении отдельного тяжёлого FBX Blender может временно не отвечать.
Остановка выполняется между архивами. Очистка удаляет все объекты текущей
сцены, включая добавленные вручную; предварительно сохраните нужный результат.
