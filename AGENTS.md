# Airmetric AGR Viewer

Пользовательский интерфейс на русском. Не менять исходные ZIP, сцены или Preferences.
Не включать сторонние исходники. Не добавлять лицензию без решения владельца.
Публичные тексты посвящены только Airmetric и Blender: установке и использованию.
Не публиковать названия заказчиков, объектов, адреса, имена рабочих архивов,
результаты проверок на закрытых данных или названия сторонних инструментов.
Внешние тестовые данные задаются параметрами и не входят в репозиторий.
Чистый Python отделять от bpy. Все тестовые данные и профили Blender — во внешней
согласованной папке Workspace/Temp/AirmetricAGRViewer. Не создавать __pycache__:
запускать python -B. Проверить unit-тесты и изолированный Blender перед коммитом.
Не публиковать релизы и не менять видимость GitHub без прямого разрешения.
